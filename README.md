# CV Ejecutivo - Leonardo Vargas Abarca

Este es un proyecto web interactivo diseñado para exponer la trayectoria profesional de Leonardo Vargas Abarca mediante una propuesta estética **ejecutiva de alta gama, sobria, formal y elegante**.

## 🎨 Características del Diseño
- **Paleta de Colores**: Un esquema cromático de lujo basado en **Negro Obsidiana** y **Gris Pizarra** con acentos refinados en **Oro Champaña** (en modo claro alterna a **Marfil Cálido** y **Crema**).
- **Tipografía Editorial**: Uso de **Lora** (Serif elegante) en títulos principales y **Inter** (Sans-serif limpia) en el texto de lectura.
- **Movimiento Atmosférico**: Animaciones lentas de luces ambientales que flotan en el fondo, brindando profundidad de forma discreta y profesional, sin elementos de código de desarrollador ni partículas ruidosas.
- **Identidad de Marca**: Monograma ejecutivo ("LV") estilizado en tipografía clásica.
- **Hoja de Impresión Ejecutiva**: La estructura en `@media print` formatea automáticamente el currículum a una plantilla formal en blanco y negro de dos páginas al generar el PDF.

## 🚀 Cómo Iniciar el Proyecto Localmente

1. Abre la Terminal en tu Mac.
2. Navega al directorio del proyecto:
   ```bash
   cd "/Users/leonardovargas/.gemini/antigravity/scratch/cv-leonardo"
   ```
3. Inicia el servidor web local de Python:
   ```bash
   python3 -m http.server 8000
   ```
4. Abre tu navegador favorito y dirígete a:
   [http://localhost:8000](http://localhost:8000)

## 📄 Descarga de CV en PDF (Alta Calidad)

1. Haz clic en el botón **"Descargar CV"** en el sitio.
2. Sigue las instrucciones del modal explicativo:
   - **Destino**: `Guardar como PDF` (o `Save as PDF`).
   - **Márgenes**: `Predeterminados` (Escala 100%).
   - **Ajustes**: Desmarca `Cabeceras y pies de página` para un acabado limpio y asegúrate de marcar `Gráficos de fondo` para mantener la fidelidad de diseño de las etiquetas.
3. Guarda el archivo resultante en tu computadora.
